HOSTELTRACK — BEGINNER PROJECT

FILES
- index.html: page structure
- style.css: styling and responsive layout
- script.js: demo student list, attendance rules, Local Storage, search, CSV export

HOW TO RUN
1. Extract this ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Open index.html in Chrome or another modern browser.
4. Use the demo matric number STU/2024/001 (or another number listed in script.js).
5. Select a movement and click Record attendance.

IMPORTANT LIMITATIONS
- This is a classroom prototype, not a secure production system.
- Data is stored in the current browser only; it does not sync between devices.
- The matric number field is not real authentication and can be impersonated.
- Demo student records and sample attendance movements are included.
- Google Fonts are optional; the page uses fallback fonts if unavailable.
